Если на вашем ноутбуке какой-то функции нет или она работает неправильно, дамп его прошивки покажет, как это устроено на самом деле. Многое из того, что OpenSense знает о вентиляторах, взято из прошивки Nitro 5 AN515-57: так выяснилось, что добавочная скорость вентиляторов задаётся только с шагом 10 %, а встроенная в прошивку кривая вентиляторов на этой модели ни на что не влияет. Список моделей, дампы которых нужнее всего, есть в [README](../README-ru.md#дампы-прошивки).

По этому руководству вы прочитаете микросхему флеш-памяти BIOS с загрузочной флешки с Linux и сохраните её содержимое в один файл. У AN515-57 в этом же файле оказалась и прошивка встроенного контроллера (EC), который управляет вентиляторами и подсветкой клавиатуры. **На ноутбук ничего не записывается.** Всё займёт около получаса.

## Что понадобится

- Флешка на 4 ГБ или больше для Linux (всё на ней будет стёрто).
- Куда сохранить дамп: вторая флешка или любой раздел ноутбука, кроме диска с Windows, например диск `D:`.
- Ноутбук должен всё время быть подключён к зарядке.

> [!IMPORTANT]
> **BitLocker.** На многих ноутбуках диск с Windows зашифрован с завода (*Шифрование устройства*). После отключения Secure Boot Windows при следующем запуске попросит ключ восстановления BitLocker. Заранее найдите этот ключ (он хранится в вашей учётной записи Microsoft: [aka.ms/myrecoverykey](https://aka.ms/myrecoverykey)) или приостановите BitLocker до тех пор, пока не включите его снова. Для этого в терминале, запущенном от имени администратора, введите:
>
> ```powershell
> manage-bde -protectors -disable C: -RebootCount 0
> ```

## 1. Подготовьте флешку с Linux

Скачайте **Linux Mint** (редакцию Cinnamon) с [linuxmint.com](https://linuxmint.com/download.php) и запишите образ на флешку с помощью [Rufus](https://rufus.ie). Настройки по умолчанию менять не нужно.

## 2. Отключите Secure Boot

Пока Secure Boot включён, Linux не даёт программам обращаться к оборудованию напрямую, а без этого микросхему не прочитать. Ниже пункты названы так, как в русской версии BIOS; если у вас BIOS на английском, ориентируйтесь на названия в скобках.

1. Перезагрузите ноутбук и, пока на экране логотип Acer, несколько раз нажмите **F2**, чтобы войти в BIOS.
2. Acer даёт изменить параметр **Безопасная загрузка** (Secure Boot) только после того, как задан пароль администратора. На вкладке **Безопасность** (Security) выберите **Установить пароль администратора** (Set Supervisor Password) и задайте пароль.
3. На вкладке **Загрузка** (Boot) переключите параметр **Безопасная загрузка** (Secure Boot) на **Отключено** (Disabled).
4. На вкладке **Главная** (Main) переключите параметр **Меню загрузки F12** (F12 Boot Menu) на **Включено** (Enabled), если он ещё не включён.
5. Нажмите **F10**, чтобы сохранить изменения и перезагрузиться.

## 3. Загрузитесь с флешки

Вставьте флешку, перезагрузите ноутбук и, пока на экране логотип Acer, нажмите **F12**. Выберите флешку, а затем **Start Linux Mint**. Linux запустится прямо с флешки и Windows не затронет.

## 4. Установите flashrom

Подключитесь к Wi-Fi или по кабелю (значок сети в правом нижнем углу), откройте **Terminal** и введите:

```sh
sudo apt update
sudo apt install -y flashrom
```

## 5. Снимите дамп

Сначала пусть flashrom найдёт микросхему. Эта команда ещё ничего не читает:

```sh
sudo flashrom -p internal
```

Она покажет название и объём микросхемы и остановится с предупреждением, что это ноутбук. Так и должно быть: на ноутбуках flashrom по умолчанию отказывается работать, чтобы случайно ничего не записать, а мы здесь только читаем. Если он нашёл несколько подходящих микросхем, добавьте к командам ниже `-c "НАЗВАНИЕ"` с одним из этих названий.

Теперь прочитайте микросхему два раза и сравните копии:

```sh
sudo flashrom -p internal:laptop=this_is_not_a_laptop -r ~/bios1.bin 2>&1 | tee ~/flashrom.txt
sudo flashrom -p internal:laptop=this_is_not_a_laptop -r ~/bios2.bin
cmp ~/bios1.bin ~/bios2.bin && echo "DUMP OK" || echo "DIFFERENT, read again"
```

Должно появиться `DUMP OK`. Если копии не совпадают, повторите обе команды чтения. Если в файле есть большие участки из одних `FF` (область Intel ME), это нормально.

Если flashrom совсем не может прочитать микросхему (такое бывает на некоторых ноутбуках с AMD), сохраните `flashrom.txt`: сообщение об ошибке из него тоже пригодится.

## 6. Сохраните дамп

Live-система хранит файлы в оперативной памяти, так что после выключения они пропадут. Откройте **Files** и нажмите на боковой панели на вторую флешку или на диск с данными, чтобы подключить его. Затем посмотрите, куда он подключился:

```sh
lsblk -o NAME,SIZE,FSTYPE,LABEL,MOUNTPOINTS
```

Скопируйте файлы в эту папку (путь из столбца `MOUNTPOINTS`, например `/media/mint/Data`):

```sh
cp ~/bios1.bin ~/flashrom.txt /media/mint/Data/
sync
```

## 7. Верните всё как было

1. Перезагрузите ноутбук, вытащите флешку и нажмите **F2**, чтобы снова войти в BIOS.
2. На вкладке **Загрузка** (Boot) переключите параметр **Безопасная загрузка** (Secure Boot) обратно на **Включено** (Enabled).
3. На вкладке **Безопасность** (Security) выберите **Установить пароль администратора** (Set Supervisor Password), введите текущий пароль, а поле нового оставьте пустым: так пароль удалится.
4. Нажмите **F10**, чтобы сохранить изменения и загрузить Windows.

Если вы приостанавливали BitLocker, включите его обратно. В терминале, запущенном от имени администратора, введите:

```powershell
manage-bde -protectors -enable C:
```

## 8. Отправьте дамп

Нужен только `bios1.bin` (и `flashrom.txt`, если прочитать не получилось). [Создайте issue](https://github.com/archivesteak/opensense/issues), напишите модель ноутбука и версию BIOS (их видно в OpenSense: **Параметры → Ваш ноутбук**) и прикрепите дамп. GitHub принимает файлы не больше 25 МБ и не всех типов: если дамп больше или GitHub его не берёт, сначала запакуйте его в `.zip`. Если и архив слишком большой, загрузите его на любой файлообменник и вставьте ссылку.

> [!WARNING]
> Issue видны всем, а в дампе есть данные вашего ноутбука: серийный номер, лицензионный ключ Windows, который Acer записала в прошивку, и пароль администратора из шага 2 (поэтому лучше, чтобы вы его больше нигде не использовали). Если не хотите их публиковать, пришлите zip (или ссылку на него) на почту [archivesteak@gmail.com](mailto:archivesteak@gmail.com), указав модель ноутбука и версию BIOS.

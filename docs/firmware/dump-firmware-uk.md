Якщо на вашому ноутбуці якоїсь функції немає або вона працює неправильно, дамп його прошивки покаже, як це влаштовано насправді. Багато з того, що OpenSense знає про вентилятори, взято з прошивки Nitro 5 AN515-57: так з’ясувалося, що додаткова швидкість вентиляторів задається лише з кроком 10 %, а вбудована в прошивку крива вентиляторів на цій моделі ні на що не впливає. Список моделей, дампи яких потрібні найбільше, є в [README](../README-uk.md#дампи-прошивки).

За цим посібником ви прочитаєте мікросхему флеш-пам’яті BIOS із завантажувальної флешки з Linux і збережете її вміст в один файл. На AN515-57 у цьому ж файлі виявилася й прошивка вбудованого контролера (EC), який керує вентиляторами й підсвічуванням клавіатури. **На ноутбук нічого не записується.** Усе займе близько пів години.

## Що знадобиться

- Флешка на 4 ГБ або більше для Linux (усе на ній буде стерто).
- Куди зберегти дамп: друга флешка або будь-який розділ ноутбука, крім диска з Windows, наприклад диск `D:`.
- Ноутбук має весь час бути підключений до зарядки.

> [!IMPORTANT]
> **BitLocker.** На багатьох ноутбуках диск із Windows зашифровано ще на заводі (*Шифрування пристрою*). Після вимкнення Secure Boot Windows під час наступного запуску попросить ключ відновлення BitLocker. Заздалегідь знайдіть цей ключ (він зберігається у вашому обліковому записі Microsoft: [aka.ms/myrecoverykey](https://aka.ms/myrecoverykey)) або призупиніть BitLocker, доки знову його не ввімкнете. Для цього в терміналі, запущеному від імені адміністратора, введіть:
>
> ```powershell
> manage-bde -protectors -disable C: -RebootCount 0
> ```

## 1. Підготуйте флешку з Linux

Завантажте **Linux Mint** (редакцію Cinnamon) з [linuxmint.com](https://linuxmint.com/download.php) і запишіть образ на флешку за допомогою [Rufus](https://rufus.ie). Налаштування за замовчуванням змінювати не треба.

## 2. Вимкніть Secure Boot

Поки Secure Boot увімкнено, Linux не дає програмам звертатися до обладнання напряму, а без цього мікросхему не прочитати. Української мови в BIOS немає, тому пункти нижче названо англійською, як на екрані.

1. Перезавантажте ноутбук і, поки на екрані логотип Acer, кілька разів натисніть **F2**, щоб увійти в BIOS.
2. Acer дає змінити **Secure Boot** лише після того, як задано пароль супервізора. На вкладці **Security** виберіть **Set Supervisor Password** і задайте пароль.
3. На вкладці **Boot** перемкніть **Secure Boot** на **Disabled**.
4. На вкладці **Main** перемкніть **F12 Boot Menu** на **Enabled**, якщо його ще не ввімкнено.
5. Натисніть **F10**, щоб зберегти зміни й перезавантажитися.

## 3. Завантажтеся з флешки

Вставте флешку, перезавантажте ноутбук і, поки на екрані логотип Acer, натисніть **F12**. Виберіть флешку, а потім **Start Linux Mint**. Linux запуститься просто з флешки й Windows не зачепить.

## 4. Установіть flashrom

Підключіться до Wi-Fi або кабелем (значок мережі в правому нижньому куті), відкрийте **Terminal** і введіть:

```sh
sudo apt update
sudo apt install -y flashrom
```

## 5. Зніміть дамп

Спершу нехай flashrom знайде мікросхему. Ця команда ще нічого не читає:

```sh
sudo flashrom -p internal
```

Вона покаже назву й об’єм мікросхеми та зупиниться з попередженням, що це ноутбук. Так і має бути: на ноутбуках flashrom за замовчуванням відмовляється працювати, щоб випадково нічого не записати, а ми тут лише читаємо. Якщо він знайшов кілька відповідних мікросхем, додайте до команд нижче `-c "НАЗВА"` з однією з цих назв.

Тепер прочитайте мікросхему двічі й порівняйте копії:

```sh
sudo flashrom -p internal:laptop=this_is_not_a_laptop -r ~/bios1.bin 2>&1 | tee ~/flashrom.txt
sudo flashrom -p internal:laptop=this_is_not_a_laptop -r ~/bios2.bin
cmp ~/bios1.bin ~/bios2.bin && echo "DUMP OK" || echo "DIFFERENT, read again"
```

Має з’явитися `DUMP OK`. Якщо копії не збігаються, повторіть обидві команди читання. Якщо у файлі є великі ділянки з самих `FF` (область Intel ME), це нормально.

Якщо flashrom зовсім не може прочитати мікросхему (таке буває на деяких ноутбуках з AMD), збережіть `flashrom.txt`: повідомлення про помилку з нього теж знадобиться.

## 6. Збережіть дамп

Live-система зберігає файли в оперативній пам’яті, тож після вимкнення вони зникнуть. Відкрийте **Files** і натисніть на бічній панелі на другу флешку або на диск із даними, щоб підключити його. Потім подивіться, куди його підключено:

```sh
lsblk -o NAME,SIZE,FSTYPE,LABEL,MOUNTPOINTS
```

Скопіюйте файли в цю папку (шлях зі стовпця `MOUNTPOINTS`, наприклад `/media/mint/Data`):

```sh
cp ~/bios1.bin ~/flashrom.txt /media/mint/Data/
sync
```

## 7. Поверніть усе як було

1. Перезавантажте ноутбук, вийміть флешку й натисніть **F2**, щоб знову увійти в BIOS.
2. На вкладці **Boot** перемкніть **Secure Boot** назад на **Enabled**.
3. На вкладці **Security** виберіть **Set Supervisor Password**, введіть поточний пароль, а поле нового залиште порожнім: так пароль видалиться.
4. Натисніть **F10**, щоб зберегти зміни й завантажити Windows.

Якщо ви призупиняли BitLocker, увімкніть його знову. У терміналі, запущеному від імені адміністратора, введіть:

```powershell
manage-bde -protectors -enable C:
```

## 8. Надішліть дамп

Потрібен лише `bios1.bin` (і `flashrom.txt`, якщо прочитати не вдалося). [Створіть issue](https://github.com/archivesteak/opensense/issues), напишіть модель ноутбука й версію BIOS (їх видно в OpenSense: **Настройки → Ваш ноутбук**) і прикріпіть дамп. GitHub приймає файли не більше 25 МБ і не всіх типів: якщо дамп більший або GitHub його не бере, спершу запакуйте його в `.zip`. Якщо й архів завеликий, завантажте його на будь-який файлообмінник і вставте посилання.

> [!WARNING]
> Issue бачать усі, а в дампі є дані вашого ноутбука: серійний номер, ліцензійний ключ Windows, який Acer записала в прошивку, і пароль супервізора з кроку 2 (тому краще, щоб ви його більше ніде не використовували). Якщо не хочете їх оприлюднювати, надішліть zip (або посилання на нього) на пошту [archivesteak@gmail.com](mailto:archivesteak@gmail.com), указавши модель ноутбука й версію BIOS.
